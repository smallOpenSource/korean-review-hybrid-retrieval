## ⚠️ 왜 동시 처리가 안 될까?

### 가능한 원인:

1. **Ollama 서버 설정**
   - `OLLAMA_NUM_PARALLEL=1` (기본값)로 설정되어 있을 가능성
   - 동시 요청 큐가 없거나 제한됨
   - 메모리/GPU 리소스 부족

2. **모델 로딩 방식**
   - exaone3.5:2.4b 모델이 한 번에 하나만 로드됨
   - 동시 inference 불가능한 구조

3. **서버 리소스 제한**
   - GPU 메모리 부족으로 여러 요청 처리 불가
   - CPU 모드에서도 메모리 제약
